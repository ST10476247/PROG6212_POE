# RaceDay RESTful API Endpoint Plan

## Project Overview
**RaceDay** is a comprehensive, full-stack, cloud-aware event management system designed specifically for the South African road running, walking, and cycling community. This specification defines all RESTful API endpoints required for **Part 2** and consumed by the MVC application in **Part 3**.

---

## Master API Endpoint Specification Table

| HTTP Method | Route | Description | Role required | Request body | Expected response |
| :--- | :--- | :--- | :--- | :--- | :--- |
| POST | /api/auth/register/participant | Registers a new athlete profile with South African ID / Passport details. | None (Public) | {"email": "string", "password": "string", "firstName": "string", "lastName": "string", "saIdOrPassport": "string", "gender": "string", "dateOfBirth": "yyyy-MM-dd", "emergencyPhone": "string", "clubName": "string"} | 201 Created - Returns new user and participant identity.<br>400 Bad Request - Validation failure.<br>409 Conflict - Duplicate email or SA ID. |
| POST | /api/auth/register/organiser | Registers a race director or timing official profile and organisation. | None (Public) | {"email": "string", "password": "string", "organizationName": "string", "contactEmail": "string", "phone": "string", "province": "string"} | 201 Created - Returns new organiser account.<br>400 Bad Request - Invalid payload.<br>409 Conflict - Organisation or email exists. |
| POST | /api/auth/login | Authenticates user credentials and issues a signed JWT bearer token. | None (Public) | {"email": "string", "password": "string"} | 200 OK - Returns JWT token, role claims, and user metadata.<br>401 Unauthorized - Invalid credentials. |
| POST | /api/auth/refresh | Generates a refreshed JWT security token prior to token expiry. | Any (Logged in) | {"refreshToken": "string"} | 200 OK - Refreshed JWT token payload.<br>401 Unauthorized - Expired or revoked token. |
| POST | /api/auth/logout | Invalidates active user session and revokes refresh tokens. | Any (Logged in) | None | 200 OK - Session successfully terminated.<br>401 Unauthorized - Token missing. |
| GET | /api/profile/me | Retrieves the authenticated user profile (demographics, club or organisation info). | Any (Logged in) | None | 200 OK - Full profile details for current user.<br>401 Unauthorized - Missing or invalid token. |
| PUT | /api/profile/me | Updates contact numbers, emergency contacts, or club affiliations. | Any (Logged in) | {"phone": "string", "emergencyPhone": "string", "clubName": "string", "organizationName": "string"} | 200 OK - Updated user profile.<br>400 Bad Request - Validation error.<br>401 Unauthorized - Unauthenticated. |
| PUT | /api/profile/change-password | Updates user security password with old password verification. | Any (Logged in) | {"currentPassword": "string", "newPassword": "string"} | 200 OK - Password successfully changed.<br>400 Bad Request - Password complexity failure.<br>401 Unauthorized - Incorrect current password. |
| GET | /api/events | Retrieves a paginated list of all upcoming, live, and completed South African events. | None (Public) | None | 200 OK - Array of event summaries with category count and location. |
| GET | /api/events/{id} | Retrieves complete event details including categories, route elevation, and weather summary. | None (Public) | None | 200 OK - Detailed event model with linked distance categories.<br>404 Not Found - Event ID does not exist. |
| GET | /api/events/search | Filters events by province, sport type (Running, Cycling, Walking), date range, and keyword. | None (Public) | None | 200 OK - Filtered collection of matching events. |
| GET | /api/events/featured | Retrieves high-profile South African road events (e.g., Comrades, Cape Town Cycle Tour). | None (Public) | None | 200 OK - List of featured national events. |
| POST | /api/events | Creates a new road running, walking, or cycling event in the platform. | Organiser | {"eventName": "string", "eventType": "Running|Cycling|Walking", "eventDate": "yyyy-MM-ddTHH:mm:ss", "location": "string", "province": "string", "description": "string", "bannerUrl": "string", "elevationGainMeters": 1250, "keyLandmarks": "string", "terrainType": "string"} | 201 Created - Created event object with eventId.<br>400 Bad Request - Invalid date or missing fields.<br>401 Unauthorized - Token missing.<br>403 Forbidden - Organiser role required. |
| PUT | /api/events/{id} | Updates event metadata, course descriptions, banner graphics, or scheduled dates. | Organiser | {"eventName": "string", "eventType": "Running|Cycling|Walking", "eventDate": "yyyy-MM-ddTHH:mm:ss", "location": "string", "province": "string", "description": "string", "status": "Upcoming|Live|Completed", "bannerUrl": "string", "elevationGainMeters": 1250, "keyLandmarks": "string", "terrainType": "string"} | 200 OK - Updated event record.<br>400 Bad Request - Validation error.<br>403 Forbidden - Not owner of event.<br>404 Not Found - Event ID not found. |
| DELETE | /api/events/{id} | Deletes an event and cascades deletion to linked categories and unconfirmed entries. | Organiser | None | 204 No Content - Event successfully deleted.<br>403 Forbidden - Forbidden.<br>404 Not Found - Event not found.<br>409 Conflict - Cannot delete event with active paid enrolments. |
| GET | /api/events/{eventId}/categories | Retrieves all distance categories, start times, entry fees, and remaining capacities for an event. | None (Public) | None | 200 OK - Array of category models.<br>404 Not Found - Event ID not found. |
| GET | /api/categories/{id} | Retrieves single category details including cutoff duration and capacity remaining. | None (Public) | None | 200 OK - Category details.<br>404 Not Found - Category ID not found. |
| POST | /api/events/{eventId}/categories | Adds a new race distance category (e.g., 89km Ultra, 42.2km, 21.1km) to an event. | Organiser | {"categoryName": "string", "distanceKm": 42.2, "entryFeeZAR": 450.00, "maxCapacity": 10000, "startTime": "06:00:00", "cutoffHours": 6.0} | 201 Created - Category object with categoryId.<br>400 Bad Request - Validation error.<br>403 Forbidden - Organiser role required.<br>404 Not Found - Event ID not found. |
| PUT | /api/categories/{id} | Updates entry fees, distance, start times, or cutoff limits for a category. | Organiser | {"categoryName": "string", "distanceKm": 42.2, "entryFeeZAR": 450.00, "maxCapacity": 10000, "startTime": "06:00:00", "cutoffHours": 6.0} | 200 OK - Updated category object.<br>400 Bad Request - Invalid parameters.<br>404 Not Found - Category ID not found. |
| DELETE | /api/categories/{id} | Removes an event category if no participants have enrolled. | Organiser | None | 204 No Content - Category deleted.<br>404 Not Found - Category not found.<br>409 Conflict - Active entries exist. |
| POST | /api/enrolments | Enrols the authenticated participant into a category, allocates a bib number, and issues a payment receipt. | Participant | {"categoryId": 1, "medicalNotes": "string"} | 201 Created - Enrolment receipt with entryId, bibNumber, and paymentReference.<br>400 Bad Request - Capacity full.<br>403 Forbidden - Participant role required.<br>409 Conflict - Already enrolled in category. |
| GET | /api/enrolments/my | Retrieves all race entry history, allocated bib numbers, and payment receipts for logged-in participant. | Participant | None | 200 OK - Array of participant enrolments with category details.<br>401 Unauthorized - Unauthenticated. |
| GET | /api/enrolments/{id} | Retrieves a single entry ticket receipt and medical alert details. | Any (Logged in) | None | 200 OK - Detailed entry object.<br>403 Forbidden - Cannot access another user's entry.<br>404 Not Found - Enrolment ID not found. |
| GET | /api/events/{eventId}/enrolments | Retrieves all participant entries, bib allocations, and medical conditions for an event roster. | Organiser | None | 200 OK - Array of registered participants for event.<br>403 Forbidden - Not owner of event.<br>404 Not Found - Event not found. |
| PUT | /api/enrolments/{id}/status | Updates payment status or refunds an enrolment. | Organiser | {"paymentStatus": "Paid|Pending|Cancelled|Refunded"} | 200 OK - Updated enrolment status.<br>400 Bad Request - Invalid status.<br>404 Not Found - Enrolment not found. |
| GET | /api/events/{eventId}/results | Retrieves public race timing results, gun/chip times, and overall/category/gender leaderboards. | None (Public) | None | 200 OK - Array of timing records sorted by rank.<br>404 Not Found - Event ID not found. |
| GET | /api/results/my | Retrieves personal performance history, chip splits, and podium statistics for current athlete. | Participant | None | 200 OK - Array of athlete race results.<br>401 Unauthorized - Unauthenticated. |
| GET | /api/results/{id} | Retrieves an individual participant timing certificate and ranking breakdown. | None (Public) | None | 200 OK - Single result detail with certificate metadata.<br>404 Not Found - Result ID not found. |
| POST | /api/results | Captures or imports an official gun and chip timing result for a registered bib entry. | Organiser | {"entryId": 1, "gunTime": "06:14:22.450", "chipTime": "06:13:58.120", "overallRank": 48, "categoryRank": 12, "genderRank": 42, "status": "Finished"} | 201 Created - Created timing result record.<br>400 Bad Request - Timing validation error.<br>403 Forbidden - Organiser role required.<br>409 Conflict - Result already captured for entry. |
| PUT | /api/results/{id} | Corrects a timing entry or adjusts DQ/DNF race status for a participant. | Organiser | {"gunTime": "06:14:22.450", "chipTime": "06:13:58.120", "overallRank": 48, "categoryRank": 12, "genderRank": 42, "status": "Finished|DNF|DNS|Disqualified"} | 200 OK - Updated result record.<br>400 Bad Request - Validation error.<br>404 Not Found - Result ID not found. |
| DELETE | /api/results/{id} | Removes an invalid or test timing record from official leaderboard. | Organiser | None | 204 No Content - Result deleted.<br>404 Not Found - Result not found. |
| GET | /api/events/{id}/weather | Retrieves real-time simulated South African weather conditions and race-day hydration advice. | None (Public) | None | 200 OK - Location weather object with temp, humidity, wind, and advice.<br>404 Not Found - Event not found. |
| GET | /api/events/{id}/route | Retrieves route elevation profile, terrain description, and iconic South African landmarks. | None (Public) | None | 200 OK - Route data with elevationGainMeters, terrainType, and landmarks list.<br>404 Not Found - Event not found. |
