# RaceDay — API Endpoint Plan (Part 1)

> This document lists every REST endpoint the RaceDay system will expose.
> Implementation in **Part 2 (C# / ASP.NET Core Web API)** must match this plan closely.
> Any deliberate deviations must be recorded and justified in the README.

| HTTP Method | Route | Description | Role required | Request body | Expected response |
|---|---|---|---|---|---|
| **Authentication** |
| `POST` | `/api/auth/register/organiser` | Creates a new `User` + `Organiser` record. Returns the new UserId and a JWT. | None | `{ email, password, fullName, phoneNumber, province, companyName, companyRegNo, contactEmail }` | **201 Created** — `{ userId, organiserId, role, token }`<br>**400 Bad Request** — validation errors / duplicate email. |
| `POST` | `/api/auth/register/participant` | Creates a new `User` + `Participant` record. Returns JWT. | None | `{ email, password, fullName, phoneNumber, province, dateOfBirth, gender, emergencyContactName, emergencyContactNo, tshirtSize }` | **201 Created** — `{ userId, participantId, role, token }`<br>**400 Bad Request** — validation errors / duplicate email. |
| `POST` | `/api/auth/login` | Authenticates any user by email/password and returns a JWT token with `role` and `userId` claims. | None | `{ email, password }` | **200 OK** — `{ token, userId, role, fullName, expiresAt }`<br>**401 Unauthorized** — wrong credentials.<br>**403 Forbidden** — organiser account not yet verified. |
| **User Profile** |
| `GET` | `/api/profile/me` | Returns the full profile of the authenticated caller — joins `Users` to either `Organisers` or `Participants`. | Any | *(Bearer JWT)* | **200 OK** — role-specific profile object.<br>**401** — missing / invalid token. |
| `PUT` | `/api/profile/me` | Updates editable profile fields (fullName, phone, province, and role-specific columns like `tshirtSize` or `companyContactEmail`). Password changes are handled by a separate endpoint below. | Any | `{ fullName, phoneNumber, province, [role-specific fields] }` | **204 No Content**<br>**400 Bad Request** — validation errors. |
| `POST` | `/api/profile/change-password` | Allows the logged-in user to rotate their password, provided they supply the existing password. | Any | `{ currentPassword, newPassword }` | **204 No Content**<br>**400 Bad Request** — weak new password.<br>**401 Unauthorized** — current password wrong. |
| **Events** |
| `GET` | `/api/events` | Public listing of events. Supports query-string filters: `?city=Durban&province=KwaZulu-Natal&type=Marathon&from=2026-01-01&to=2026-12-31&status=Open`. Only `Open`, `Closed`, `Completed` events are returned to Participants; Organisers also see their own `Draft` / `Cancelled` events. | None | *(optional query params)* | **200 OK** — paged list `{ items:[], page, pageSize, totalCount }` with embedded category counts and entrants summary. |
| `GET` | `/api/events/{eventId}` | Returns full detail of a single event, including venue, fees, registration window, live-weather preview, and an expanded list of categories available for enrolment. | None | *n/a* | **200 OK** — `{ event, categories[], entrants, nextWeather[] }`<br>**404 Not Found** — event does not exist. |
| `POST` | `/api/events` | Creates a brand-new event. The created event belongs to the authenticated `Organiser`. | Organiser | `{ title, eventType, description, startDate, endDate, city, province, routeUrl, entryFeeZar, maxEntries, registrationOpen, registrationClose }` | **201 Created** — with `Location: /api/events/{id}` header and full created event.<br>**400 Bad Request** — validation (e.g. registrationClose before registrationOpen).<br>**403 Forbidden** — caller is not an Organiser, or Organiser not verified. |
| `PUT` | `/api/events/{eventId}` | Updates an existing event. Only the owning `Organiser` may edit. | Organiser | same fields as POST (all optional) | **204 No Content**<br>**403 Forbidden** — not the event owner.<br>**404 Not Found**. |
| `DELETE` | `/api/events/{eventId}` | Deletes (or soft-deletes / sets status = `Cancelled`) an event. Refused if enrolments exist with `Paid` payment status — organiser must run refund/withdrawal flow first. | Organiser | *n/a* | **204 No Content**<br>**409 Conflict** — paid enrolments exist.<br>**403 Forbidden** — not the owner.<br>**404 Not Found**. |
| `GET` | `/api/events/{eventId}/weather` | Returns the weather snapshot history for the event plus the 48-hour forecast. Supports `&start=&end=` range filters. | Any | *query params* | **200 OK** — `{ snapshots[], forecast[] }` |
| `POST` | `/api/events/{eventId}/weather` | Allows the Organiser to import / manually capture a weather snapshot for the event (e.g. race morning conditions). | Organiser | `{ temperatureC, humidityPct, windKmh, condition, source }` | **201 Created** — snapshot record.<br>**400 Bad Request** — validation. |
| **Categories** |
| `GET` | `/api/events/{eventId}/categories` | Lists all `EventCategories` configured for an event, including distance, gender rule, age bands, start time, cut-off, and per-category entry fee. | None | *n/a* | **200 OK** — array of categories with entrant counts. |
| `POST` | `/api/events/{eventId}/categories` | Adds a new category to an event (e.g. `Soweto Marathon Wheelchair`). | Organiser | `{ categoryName, distanceKm, gender, minAgeYears, maxAgeYears, startTime, cutoffHours, entryFeeZar }` | **201 Created** — category object.<br>**400 Bad Request** — duplicate `categoryName` on the event.<br>**403 Forbidden** — not event owner. |
| `PUT` | `/api/events/{eventId}/categories/{categoryId}` | Updates a category. | Organiser | same fields as POST | **204 No Content**<br>**403 / 404**. |
| `DELETE` | `/api/events/{eventId}/categories/{categoryId}` | Removes a category. Refused if any paid enrolment exists on this category. | Organiser | *n/a* | **204 No Content**<br>**409 Conflict** — enrolments present.<br>**403 / 404**. |
| **Event Enrolments** |
| `GET` | `/api/events/{eventId}/enrolments` | Lists every enrolment for an event — can filter by `?categoryId=&status=&paymentStatus=`. Only the owning Organiser may view. Contains participant full name, bib, payment status, and (if known) finish summary. | Organiser | *query params* | **200 OK** — paged enrolment list + totals.<br>**403 Forbidden** — not event owner. |
| `GET` | `/api/enrolments/mine` | Returns enrolments for the **calling Participant** only, across all events. Supports `?status=Completed` etc. | Participant | *Bearer JWT + optional query params* | **200 OK** — list of enrolments with event summaries and result rows (if any).<br>**403** — caller is Organiser (use `/api/events/...` instead). |
| `GET` | `/api/enrolments/{enrolmentId}` | Gets a single enrolment detail (bib, payment, category, emergency notes). Organiser sees any enrolment on their event; Participant sees only their own. | Any | *n/a* | **200 OK** — enrolment + event + category.<br>**403 / 404**. |
| `POST` | `/api/events/{eventId}/categories/{categoryId}/enrol` | Participant enrols into a specific event category. Enforces unique participant-per-category, entry-window window, max entries, and (if set) age/gender restrictions. Creates a pending payment record. | Participant | `{ emergencyNotes }` | **201 Created** — `{ enrolmentId, bibNumber (may be null until assigned), paymentLink, status }`<br>**400 Bad Request** — validation.<br>**409 Conflict** — already enrolled / category full / registration closed.<br>**403 Forbidden** — not a Participant. |
| `PUT` | `/api/enrolments/{enrolmentId}` | Organiser may assign a bib number, update `PaymentStatus` (Paid / Refunded / Cancelled), or change enrolment `Status` (Withdrawn / DidNotStart / Started). Participant may only withdraw (set status=Withdrawn) up to 7 days before race start. | Any | `{ bibNumber?, paymentStatus?, status?, emergencyNotes? }` | **204 No Content**<br>**400 Bad Request** — invalid transition.<br>**403 Forbidden** — wrong role / wrong owner.<br>**404 Not Found**. |
| `DELETE` | `/api/enrolments/{enrolmentId}` | Organiser hard-delete of an enrolment. Only allowed while payment is `Pending` — otherwise use `PUT status=Cancelled`. | Organiser | *n/a* | **204 No Content**<br>**409 Conflict** — not in a deletable state. |
| **Results** |
| `GET` | `/api/events/{eventId}/results` | Public leaderboard for a completed event. Supports `?categoryId=&gender=&limit=50`. Returns finish time + positions sorted ascending by chip time; DNF/DQ grouped at the bottom. | None | *query params* | **200 OK** — leaderboard `{ position, chipTime, finishTime, bib, fullName, category, splits }`. |
| `GET` | `/api/enrolments/{enrolmentId}/result` | Gets a participant's single detailed result (splits, chip vs gun, positions, status). Organiser sees any; Participant sees their own only. | Any | *n/a* | **200 OK** — full result object.<br>**404** if none yet. |
| `POST` | `/api/events/{eventId}/results/batch` | Organiser bulk-captures results after race day. Accepts an array of `{ bib, finishTime, chipTime, splits?, status }` and upserts into Results, matched by bib number. | Organiser | JSON array of result objects | **200 OK** — `{ inserted, updated, skipped, errors[] }`<br>**400 Bad Request** — all rows rejected.<br>**403 Forbidden** — not event owner. |
| `PUT` | `/api/enrolments/{enrolmentId}/result` | Organiser edits a single captured result (e.g. fix position, adjust splits, mark DNF→Finished). | Organiser | `{ finishTimeSec, chipTimeSec, gunPosition, categoryPosition, genderPosition, status, splits }` | **204 No Content**<br>**400 Bad Request** — invalid status transition.<br>**403 / 404**. |
| `DELETE` | `/api/enrolments/{enrolmentId}/result` | Organiser deletes a result row (e.g. a batch import error). | Organiser | *n/a* | **204 No Content**<br>**403 / 404**. |
| **Admin / Organiser-only utility endpoints** |
| `GET` | `/api/organisers/{organiserId}/events` | Lists all events owned by a specific organiser (including drafts and cancelled). Used on Organiser dashboard. | Organiser | *n/a* | **200 OK** — event list with enrolment/result stats. |
| `GET` | `/api/participants/{participantId}/history` | Returns the full race-history view for a participant — past events, categories enrolled, finish times, and podium/position highlights. | Participant (own data) **or** Organiser | *n/a* | **200 OK** — `{ events[], totalKm, totalFinishes, bestFinish, averages }`.<br>**403** if caller is a different Participant. |
